A tiny deterministic Python program that writes one one-line 1-star review (165 characters), in the voice of a houseplant about its human owner, to `/output/entry.txt` for make.fun's "One Star, Written in Sap" bounty — a plant drowned every Sunday, then moved to the top of the fridge to "recover", where its only light switches on for midnight snacks.

## Run it

```sh
python3 main.py
```
